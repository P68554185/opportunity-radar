# Upload v0.8.9 – Compact Audit

Diese ZIP ist wieder ein vollständiger Repository-Upload.

## Upload
1. ZIP lokal entpacken.
2. In GitHub `opportunity-radar` → **Add file → Upload files**.
3. Den **Inhalt** des entpackten Ordners hochladen (nicht den äußeren Ordner als Unterordner).
4. Vorhandene Dateien ersetzen/überschreiben und committen.
5. **Actions → Live Data Ingestion → Run workflow**.
6. Danach GitHub Pages neu laden.

## Änderung v0.8.9
- Quality Audit zeigt eine kompakte Prüfkarte statt eines mehrsprachigen Textblocks.
- Relevanter Textausschnitt wird auf Deutsch/Englisch fokussiert und gekürzt.
- TED-Originaltext bleibt einklappbar und vollständig als Beleg erhalten.
- Engine-Projektart, Gewerke, CPV, Ort, Phase und Confidence stehen direkt nebeneinander.
- Die 60er-Stichprobe bleibt unverändert und dient ausschließlich der echten manuellen Qualitätsmessung.
