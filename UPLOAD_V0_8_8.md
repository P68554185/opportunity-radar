# Opportunity Radar v0.8.8 – Readable Audit

1. ZIP entpacken.
2. Den **Inhalt** dieses Ordners in das Root-Verzeichnis des GitHub-Repositories `opportunity-radar` hochladen und vorhandene Dateien ersetzen.
3. Unter **Actions → Live Data Ingestion → Run workflow** den Workflow einmal starten.
4. Nach erfolgreichem Lauf die GitHub-Pages-Seite neu laden (ggf. Strg+F5).

## Neu in v0.8.8
- Multilinguale TED-Titel werden für das manuelle Audit auf einen lesbaren relevanten Text reduziert.
- Original-TED-Text bleibt vollständig über „TED-Originaltext anzeigen“ kontrollierbar.
- Audit-CSV nutzt die bereinigten Titel/Beschreibungen.
- Eigener v0.8.8 Browser-Speicher, damit alte Testklicks nicht die neue Stichprobe verfälschen.
- Versionsanzeige und Status auf v0.8.8 vereinheitlicht.

Wichtig: Es wird weiterhin keine Precision erfunden. Sie entsteht erst aus manuellen Bewertungen.
